## 🚀 Key Pipeline Implementations

*   **SAST (Static Application Security Testing):** Powered by **CodeQL** Semantic Engine for automated code structure review.
*   **SCA (Software Composition Analysis):** Configured via **Dependabot** & **Trivy** to continuously index upstream library vulnerabilities.
*   **DAST (Dynamic Application Security Testing):** Automated via **OWASP ZAP** Baseline scan for runtime endpoint evaluation.
*   **Live Infrastructure Telemetry:** Integrated with **UptimeRobot Suite** for continuous validation and outage capturing.

## 🛡️ Governance & Branch Protection
The deployment infrastructure operates under strict enterprise governance rulesets:
*   **Mandatory Pull Requests:** Enforced branch protection on `main` to prevent unauthenticated direct code alterations.
*   **Linear Anti-Deletion Guard:** Structural deletion restriction and block settings enforced on active code production lines.
